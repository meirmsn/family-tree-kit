# Brief: archive / office request (draft only — the user sends it)

A catalogue unit that **exists but has 0 scans** online is an archive request, not a negative search. Prefer those (and restricted/recent years) when choosing what to ask for. See `docs/research-process-lessons.md` §2 and `templates/online-exhaustion.md`.

1. **Find the right holder** first (records over ~100 years old usually moved to the state archive;
   check which archive holds which years). Read the archive's own contact page and cite it.
2. **Draft in the office's language**, then a full **English translation** below it:
   precise subject line; numbered requested records (names with variants, years, places, parents);
   why we think they are there (cite S-numbers in the English part only).
3. **Ask for the procedure and the cost before any search starts**, and how to pay from abroad.
4. **No proof of descent, ID copies or attachments unless the office asks.**
5. Placeholders like `[street, city, ZIP]` for anything the user must fill. Never invent them.
6. Sign the way the user signs (name form, place, their email).
7. Save as `drafts/YYYY-MM-DD_TO-SEND_<code>.md` with: code (A, B, …), priority, recipient address and
   source of that address, subject, body, translation, and a **Before sending** checklist
   (ask the family X first; delete item 3 if Y may be living; try the online search first).
8. Hand it to the user. **Do not send.** When the user says it went out: add it to the request
   table (code, archive, what, date sent, status awaiting/hold/replied/closed), and archive the draft
   as sent (`drafts/sent/YYYY-MM-DD_SENT_<code>.md`). Replies go in `correspondence/<archive>_<date>/`.
