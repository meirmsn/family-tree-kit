# Brief: first pass (free sources only)

Use with `../WORKER_BRIEF.md`. Goal: a first sweep over free, public sources for every direct-line
person the interview produced, to turn lore into records where possible.

Tasks to put in the brief, in order:
1. For each direct ancestor, weakest or shortest line first: run the standard sweep
   (METHODOLOGY §3.2) using the region files in `agent/sources/` — indexes, then scans, then
   Holocaust-era, burials, migration, destination-country civil records, context, user trees (hints).
2. Prefer records that name parents (marriages, deaths with parents, gravestones with the father's
   name, Pages of Testimony, naturalisation files).
3. For every hit: image + crop + sidecar; mine it for parents, maiden names, ages, places,
   witnesses, informants, house numbers, marginal notes (METHODOLOGY §3.3). New names → `leads.md`.
4. Log every negative and every block. List sites where a free login would help, with why.
5. End with the README status block "How far back each line reaches".

Do **not**: log in anywhere, pay, contact anyone, or start collateral research.
