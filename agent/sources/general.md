# General / worldwide

| Source | What | Access | Notes |
|---|---|---|---|
| FamilySearch — https://www.familysearch.org/ | historical record indexes, digitised microfilm (catalogue → film → image), wiki | free; **login** needed for most images | The catalogue (search by place) lists films per town and years. Some films are viewable only at affiliate libraries. Cite the ark id (`ark:/61903/…`). |
| FamilySearch Wiki — https://www.familysearch.org/en/wiki/ | which records exist where, per country/town | free | Use it to plan a sweep. |
| JewishGen — https://www.jewishgen.org/databases/ | many indexes (by country), KehilaLinks town pages, yizkor book translations | free **login** | Searches by Daitch–Mokotoff soundex. |
| Geni, WikiTree, MyHeritage public pages | user-contributed trees | free to view (some need login) | **Hints only**; at most *probable* when they match records. Cite as user trees. |
| Gazetteers: JewishGen Communities database, Wikipedia (administrative history), Mapy/OpenStreetMap | which district/province a village belonged to in a given year | free | Two villages with the same name in different districts are a classic trap: confirm the district from the archive inventory. |
| Forebears (surname distribution) | how rare a surname is | free | Context only. |
