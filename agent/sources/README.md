# Source catalogue (free sources first)

One file per region or record type. Each entry: what it has, how to query it, free or login, known
blocks and throttling. **Starter lists**: verify a link the first time you use it and add what you
learn (codes, URL patterns, quirks) with the date — in your private notes, or in a pull request to
the kit if it contains nothing personal.

| File | Covers |
|---|---|
| [general.md](general.md) | worldwide: FamilySearch, JewishGen, user trees (hints only), gazetteers |
| [poland.md](poland.md) | Russian Poland / Congress Poland, Polish State Archives, JRI-Poland, Geneteka |
| [galicia-ukraine.md](galicia-ukraine.md) | Austrian Galicia (today Poland/Ukraine), Ukrainian oblast archives |
| [romania-bukovina.md](romania-bukovina.md) | Romania, Bukovina, Moldavia |
| [holocaust.md](holocaust.md) | victims' and survivors' records, testimonies, memorial books |
| [burials.md](burials.md) | cemetery indexes, gravestones, community burial lists |
| [migration-americas.md](migration-americas.md) | ports, passenger lists, naturalisation, US/Canada/UK |
| [latin-america.md](latin-america.md) | Spanish- and Portuguese-speaking countries |

General rules (from `agent/rules.md`): free and public first; pause ≥ 12 s between index queries;
one request at a time for scans; log every block; never bypass a wall; logins only with approval.
Index = at most *probable* until you read the image.
